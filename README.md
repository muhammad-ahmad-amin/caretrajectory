# CareTrajectory — Strict ML Project

Predicting sepsis onset (PhysioNet 2019) and clinical outcomes (MIMIC-IV Demo)
using classical ML: feature engineering + RF / XGBoost / LightGBM / SVM.

## Layout
- data/             raw datasets
- data_processed/   feature-ready tables
- src/              importable code
- notebooks/        exploration
- scripts/          reproducible runs
- experiments/      per-run artifacts
- models/           saved models
- reports/          figures, tables
- configs/          YAML configs
- logs/             run logs
